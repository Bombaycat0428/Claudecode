自動ログイン設定手順（Windows 10 / 11 共通）

  1. キーボードの Windows + R を同時に押します。
  2. 名前の欄に netplwiz と入力して Enter を押します。
  3. 「ユーザー アカウント」画面が開いたら、自動ログインさせたいアカウントを選択して選択状態（青く反転）にします。
  4. 「ユーザーがこのコンピューターを使うには、ユーザー名とパスワードの入力が必要」 のチェックを外します。
  5. 「適用」を押すとパスワード入力画面が出るので、該当アカウントのパスワードを入力して 「OK」 を押します。

※「チェックボックスが表示されない」場合

Windows 11 や最近の Windows 10 では、セキュリティ設定によってチェックボックスが非表示になっていることがあります。

その場合は、以下を確認・変更してください。

設定アプリ ＞ アカウント ＞ サインイン オプション

「安全のため、このデバイスでは Microsoft アカウントに対して Windows Hello サインインのみを許可する」 という項目を 「オフ」 に変更してから、再度 netplwiz を開きます。

この画面はサンプルです。実際の Windows の画面とは異なる場合があります。
